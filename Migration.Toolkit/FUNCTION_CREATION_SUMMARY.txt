FUNCTION CAPABILITIES:
======================
✅ Analyzes source and target AD discovery outputs
✅ Detects duplicate sAMAccountNames across forests
✅ Detects duplicate UPNs (users only)
✅ Detects duplicate mail attributes
✅ Filters to show ONLY cross-forest duplicates
✅ Supports JSON config file (default provided)
✅ Supports individual parameters (override config)
✅ Generates CSV reports (AD__Duplicate__Objects__Cross_Forest.csv)
✅ Returns objects for programmatic processing (-PassThru)
✅ Provides conflict summaries (user/group/computer breakdown)

USAGE EXAMPLES:
===============

# 1. Quick run with default config
Invoke-AdCrossForestDuplicateCheck

# 2. With custom directories
Invoke-AdCrossForestDuplicateCheck `
  -SourceRunRoots 'C:\Reports\Source1', 'C:\Reports\Source2' `
  -TargetRunRoot 'C:\Reports\Target' `
  -OutputRoot 'C:\Reports\Output'

# 3. Get objects for processing
$dups = Invoke-AdCrossForestDuplicateCheck -PassThru
$critical = $dups | Where-Object { $_.Severity -eq 'High' }
$critical | Export-Csv "conflicts.csv"
