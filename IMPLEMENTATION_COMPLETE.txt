## How to Use (Right Now)

### Option 1: One-Line Automated (Simplest)
```powershell
Invoke-LcDiscoveryComparison -CustomerName "Your Org" -OpenReports
```
✅ Runs both discoveries, generates all reports, opens them automatically

### Option 2: Interactive Quick-Start
```powershell
.\Start-LcMigrationComparison.ps1
```
✅ Answers prompts, runs workflow, displays results

### Option 3: Custom Workflow
```powershell
$results = Invoke-LcDiscoveryComparison `
  -SourceServer "dc1.source.com" `
  -TargetServer "dc1.target.com" `
  -OutputRoot "E:\Reports" `
  -CustomerName "Acme Corp"

# Access individual reports
$results | Format-Table
```
✅ Full control over all parameters
